# Job listing Dashboard

A small job listing dashboard built with React, Redux and Tailwindcss. The app uses a mock JSON data source and demonstrates search, filtering, a job detail page, loading and error states, form validations and a clean component-based architecture.

This repository fulfills the following project requirements:



Currently, two official plugins are available:

- Fetch jobs from a mock JSON
- Search and filter jobs
- Responsive design
- Job detail modal/page
- Loading + error states
- Clean reusable components
- Use Redux (Redux Toolkit)
- Use proper form validations (react-hook-form)
